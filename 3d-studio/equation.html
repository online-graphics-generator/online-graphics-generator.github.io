How the equation tool works
  1. Each pair (u, v) identifies one point on a rectangular parameter grid.
  2. The three expressions return that point's x, y, and z coordinates.
  3. Use 2*PI*u or 2*PI*v for a full rotation. Use sliders a-d as live variables.
  4. Raise Resolution for smoother geometry, then choose Add to World.

Example wave: x=(u-.5)*2, y=sin(a*PI*u)*cos(b*PI*v)*c, z=(v-.5)*2.
