About

This application allows the creation of some really interesting visual effects and interference patterns that can be static or animated.

Instructions

1. Click anywhere on the canvas to create a particle.

2. Use the controls to set particle properties such as color, rays, and length.

3. Drag a particle to move it, or select it to modify its properties using the input fields.

4. Use the "Start Animation" button to begin animations, and export videos using the export button.
